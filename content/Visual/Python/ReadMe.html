Visuelle Kryptographie

Das Skript zerlegt ein schwarz-weißes Bild in zwei Folien. Jede Folie für sich zeigt nur Rauschen; legt man beide übereinander, erscheint das Bild.

  1. Das Bild ins PBM-Format umwandeln, etwa mit ImageMagick:
    magick MeinBild.png -monochrome MeinBild.pbm
    (bei ImageMagick 6 convert statt magick)
  2. Das Skript im selben Verzeichnis starten und die Dateinamen ohne .pbm eingeben:
    python3 visuelle_krypto.py
  3. Die Folien zum Drucken vergrößern; große Punkte lassen sich leichter übereinanderlegen:
    magick Folie1.pbm -scale 400% Folie1.png
    Beide auf Transparentfolie drucken und übereinanderlegen.
