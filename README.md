# Weiterleitung

Die Seite ist von <https://agag-rptu.github.io/KryptoWeb/> nach
<https://crypto.math.rptu.de/> umgezogen. GitHub Pages liefert aus diesem Branch nur
noch eine Seite aus: `index.html` für die Startseite und dieselbe Datei als `404.html`
für jeden anderen Pfad. Sie leitet auf denselben Pfad unter der neuen Adresse weiter,
damit alte Links und die QR-Codes auf gedruckten Blättern funktionieren.

Die Seite selbst entsteht aus `main`, siehe README dort.
